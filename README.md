# Nostra - E-commerce Website

Nostra is a responsive e-commerce website created as a learning project using HTML, Tailwind CSS, and JavaScript.

The website is designed to provide a simple and user-friendly shopping experience with product searching, filtering, responsive navigation, and interactive elements.

## Features

- Responsive navigation bar
- Mobile side menu
- Offer banner with close button
- Responsive hero image slider
- Shop by Category section
- New Arrival section
- Most Wanted products section
- Favourite/heart interaction
- Product search functionality
- Filter products by:
  - Occasion
  - Color
  - Arrivals
- Newsletter section
- Contact page
- Responsive design for different screen sizes

## Pages

### Home
The home page includes the hero section, brands, categories, new arrivals, most wanted products, newsletter, and footer.

### Collections
The collections page displays products with search and filtering functionality.

### Contact
The contact page provides a simple contact section for users to get in touch.
